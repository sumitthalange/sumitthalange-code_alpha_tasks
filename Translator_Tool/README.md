# 🌐 LinguaFlow – Language Translation Tool

A simple GUI-based language translation project built with Python.

## Features
- Source and target language selection
- Translation through the MyMemory Translation API
- Clean dark-mode GUI
- Swap languages button
- Copy translated result
- Error handling for internet/API problems

## Run
```bash
pip install -r requirements.txt
python app.py
```

Internet access is required because the application sends the entered text to the translation API.

## Technologies
Python • CustomTkinter • Requests • REST API
