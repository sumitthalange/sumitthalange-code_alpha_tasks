# 🤖 AI FAQ Chatbot

An AI-powered **FAQ Chatbot built with Python** that understands user questions and provides relevant answers instantly. The project uses **Natural Language Processing (NLP)** to identify the user's query and match it with the appropriate FAQ response.

## ✨ Features

- 💬 Interactive chatbot interface
- 🧠 NLP-based question understanding
- ❓ Answers frequently asked questions
- ⚡ Fast and simple responses
- 🔍 Text preprocessing and matching
- 🖥️ Easy to run locally
- 📚 Customizable FAQ dataset

## 🛠️ Tech Stack

- **Python**
- **NLTK / spaCy** – Natural Language Processing
- **JSON** – FAQ data storage
- **Git & GitHub** – Version control

## 📂 Project Structure

```text
FAQ-Chatbot/
│
├── chatbot.py
├── faq_data.json
├── requirements.txt
└── README.md
```

## ⚙️ How It Works

1. User enters a question.
2. The chatbot preprocesses the input.
3. NLP techniques analyze the question.
4. The input is matched with the FAQ dataset.
5. The most relevant answer is displayed.

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/FAQ-Chatbot.git
cd FAQ-Chatbot
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the chatbot:

```bash
python chatbot.py
```

## 💡 Example

```text
User: What are your working hours?

Bot: Our working hours are 9:00 AM to 6:00 PM.
```
